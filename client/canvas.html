    Containment (actor quarantine)

    The only supported mutation. Preview first, commit second — staging is not committing. This quarantines an actor, not a single memory.

    Log in to commit (MNEME checks authority) Not logged in. Reading needs no login.
    1. Observe: find the card the server marks taint-flagged or quarantined.
    2. Investigate: select it and read provenance, custody chain and typed relationships.
    3. Preview: stage the actor containment and see exactly what would be flagged.
    4. Compare: run a counterfactual and read removed/entered/rank changes.
    5. Explain: check claim changes and decision dependencies (field-wide, kept separate).
    6. Preserve: export the evidence bundle. Integrity of the file is not truth of every claim.
